The particular challenges I faced in implementing my router were that often the shortest path wasn't found and also that when a link went down, the router wasn't able to get the ping to the correct destination. The issue in terms of not finding a shortest path was due to the fact that, when an update packet came in, I was using the get_distance value from the update + the current shortest path to the packet source rather than the direct link distance to the packet source in comparing whether or not I should update my forwarding table. The issue about a link down and having the ping arrive to the incorrect destination was due to not setting paths which used the downed link as a next hop to infinity distance too when doing poison reverse. In general though, understanding the api and available functions in the sim was a big upfront challenge to getting started with the project. Until I understood how the routers were working and how they were implemented, I could not start coding a solution.

2. This specification has packets be sent to the path with the lowest port number when two or more ports have a path with equal distance to a destination. In terms of the most efficient data transfer, being able to implement a system that sends packets equally or randomly amongst those links with equal distance/latency to their destination increases how much bandwidth you have to get more data across quicker. This isn;t an optimization in the spec, but it surely could be implemented.

3. My router uses link weights and incremental updates. In terms of link weights, keeping information about the weight of the direct link to each neighboring router and also the weight of the fastest path to every possible destination is important to forward packets correctly and also adjust for downed links correctly. Incremental updates required me to keep a list of changes to the forwarding table when an update packet was received. The router could then send an update packet only with those changes, rather than the entire forwarding table, to the neighboring routers.
